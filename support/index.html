SUPPORT

Help for the creator-controlled workflow.

TikTok connection

In Orynthian Post, open Accounts and use CONNECT TIKTOK. If the button is unavailable, the TikTok Client Key, Client Secret, or loopback redirect configuration has not been set for the Windows user running the app. Follow the local setup guide provided with Orynthian Post, then close and relaunch the app.

Disconnect an account

Open Accounts, select DISCONNECT for TikTok, and confirm the app returns to a disconnected state. This removes the app's connected-account record and encrypted tokens. You may also revoke access from TikTok's account controls.
